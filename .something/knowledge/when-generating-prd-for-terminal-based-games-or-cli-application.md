# Trigger
When generating PRD for terminal-based games or CLI applications

# Content
For terminal-based game projects like Tetris:

1. **Scope Analysis**: Projects typically require moderate complexity with cross-platform terminal considerations
2. **Key Sections**: Always include User Stories for user-facing games, Technical Considerations for terminal rendering constraints, and Risk Assessment for platform compatibility issues
3. **Terminal-Specific Requirements**: Include NFRs for ANSI support, screen refresh rates, and input responsiveness
4. **Platform Considerations**: Address Unix/Linux/macOS as primary targets with Windows as optional scope
5. **User Stories**: Focus on terminal enthusiasts, casual gamers, and retro gaming fans as core personas
6. **Open Questions Pattern**: Address remaining scope questions (Windows support, test coverage, advanced features) in appendices for stakeholder decision-making
